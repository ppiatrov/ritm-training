# РИТМ v2 — приватный журнал тренировок

Простое статическое веб-приложение для домашнего спорта, велосипеда и восстановления. Работает без сторонних библиотек и сервера. **Исходники не содержат персональных показателей или скриншотов Garmin.**

## Функции

- Календарь **неделя / месяц**, в недельном виде внутри каждого дня показаны запланированные упражнения, число подходов, повторения, вес и прогресс.
- Редактор подходов: факт повторений / секунд, **добавленный** вес (кг), отметка каждого подхода, дополнительные подходы.
- Статусы тренировки: в плане, выполнена, перенесена, пропущена.
- При пропуске: **причина** (болезнь, недосып, усталость, стресс, нехватка времени), заметка и необязательный скриншот Garmin, привязанный к записи.
- Аналитика: соотношение выполненных / пропущенных / ожидаемых силовых тренировок по неделям, число выполненных подходов. Не трактовать процент выполнения как медицинский показатель.
- План A/B на четыре недели, утренняя зарядка, велосипед, сноуборд, ссылки на технику упражнений (открываются только по нажатию).
- Дневник Garmin (ВСР, пульс покоя, сон, Body Battery, стресс, самочувствие), скриншоты, экспорт/импорт резервной копии JSON и экспорт CSV.

## Локальный запуск

Откройте `index.html` в Chrome/Edge на компьютере. Если в режиме `file://` не сохраняются данные, из каталога можно выполнить `python -m http.server 8000` и открыть `http://localhost:8000`. Для iPhone потребуется HTTPS-размещение.

Сайт не имеет зависимости от npm, сборки и внешних CDN. Все скриншоты хранятся локально в IndexedDB, а состояние — в localStorage браузера. Текущая версия продолжает использовать ключ `ritm-private-v1` и сохраняет совместимость с резервной копией v1.

## Загрузка в GitHub

**Не загружайте в публичный репозиторий.** Создайте пустой **Private** репозиторий `ritm-training` на GitHub. Затем загрузите только:

- `.gitignore`, `README.md`, `CHANGELOG.md`, `index.html`, `styles.css`, `app.js`, `sw.js`, `manifest.webmanifest`, `icon.svg`

Не загружайте персональные экспортные JSON, CSV, фотографии Garmin, свои медицинские данные или секреты. `.gitignore` снижает риск случайного коммита, но не заменяет проверку списка файлов.

**GitHub Pages не обеспечивает приватность сайта только потому, что репозиторий закрыт.** Используйте хостинг с аутентификацией, если сам интерфейс должен открываться только владельцу. Для запуска на iPhone через HTTPS необходима отдельная настройка защищённого размещения.

## Приватность и реальные ограничения

- Приложение не передаёт записи на сервер, не использует стороннюю аналитику, облако или SDK. `Content-Security-Policy` ограничивает сетевые обращения из страницы. Ссылки на YouTube открываются только вручную.
- **Данные не зашифрованы и не защищены паролем.** Человек с доступом к разблокированному устройству и профилю браузера может их прочитать. Это пока НЕ многопользовательский защищённый продукт.
- Между iPhone и компьютером нет автоматической синхронизации: у каждого браузера собственная база. Резервная копия через «Данные и настройки» переносится вручную; JSON содержит изображения и другую личную информацию **без шифрования**.
- ChatGPT не получает доступа к записям автоматически. Для разбора и корректировки программы необходимо вручную экспортировать JSON и прикрепить его к доверенной беседе. Автоматическую интеграцию с AI можно проектировать отдельно после согласования безопасности и прав доступа.
- Safari может очищать локальные данные. Регулярно сохраняйте резервные копии в защищённом месте.
- Автоматические пороги ВСР являются только справочными сигналами. Симптомы, болезнь и самочувствие приоритетнее любых часов.

## Проверки

Проверено в Chromium с тестовой DOM-страницей для ширины 1440 и 390 px: недельный календарь, 10 полей подходов для плана A, изменение веса и повторений, сохранение отметки подхода, пропуск с причиной и построение недельных графиков. Синтаксис JS проверен `node --check`. Тесты не выполнялись на реальном iPhone. Хранение и загрузка скриншотов через IndexedDB на iPhone требуют отдельной проверки после HTTPS-развёртывания.

## iPhone (Safari) + Vercel — приватный веб-доступ

1. Подключить GitHub-репозиторий `ppiatrov/ritm-training` к Vercel через Import Git Repository. Framework Preset: **Other**; Root Directory: `./`; Build Command: **не требуется**; Output Directory: **не задавать**.
2. **До использования** открыть Vercel Project → Security → Deployment Protection → Vercel Authentication → **All Deployments**. Включить проверку владельца для всех адресов (production и preview). Проверить в приватном окне, что без входа сайт не открывается. Оставить единственным участником проекта владельца.
3. На iPhone открыть защищённый HTTPS-адрес в Safari, авторизоваться в Vercel, выбрать **Поделиться → На экран «Домой»**.
4. Первую запись Garmin и тренировку сделать в **установленном приложении** и проверить после перезапуска. Safari и режим Home Screen могут иметь раздельные хранилища — журнал не синхронизируется между ними.
5. В разделе Данные и настройки регулярно делать **резервную копию JSON**; файл содержит личные данные в открытом виде — хранить только в защищённом месте, не коммитить в GitHub.

**Ограничение:** сервис хостит только статический код. Журнал и фотографии в localStorage/IndexedDB iPhone, и не передаются на Vercel, GitHub или ChatGPT. Для анализа в ChatGPT требуется ручной экспорт и загрузка. Доступ к разблокированному iPhone обеспечивает доступ к журналу, т.к. шифрование в браузере не реализовано. Смена устройства / удаление сайта / очистка данных могут удалить записи.

**Проверка безопасности:** Vercel Authentication должен покрывать **All Deployments**, а не только preview. Приватный репозиторий НЕ означает приватную публикацию.
