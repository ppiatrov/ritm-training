# Изменения — было → стало

| Было (v1) | Стало (v2) |
|---|---|
| Месячный календарь с точками | **Неделя + месяц**, в неделе внутри каждого дня — упражнения, подходы, повторения, дополнительный вес и статус |
| Только галочка на упражнение | Редактор каждого подхода: повторения/секунды, кг, выполнено; можно добавить подход |
| Пропуск одним нажатием | Пропуск с указанием причины и возможностью прикрепить скриншот Garmin |
| Общее число выполненных тренировок | Недельные графики: выполнено / пропущено / в плане; фактически отмеченные подходы |
| Скриншоты только с датой | Можно привязать скриншот к конкретной тренировке |
| Экспорт без информации о подходах | В CSV добавлены фактические подходы, дополнительный объём и причина пропуска; в JSON сохраняется связь снимка и тренировки |
| Отдельный план без весов | План A/B с редактируемыми фактическими весами и повторениями |

**Не реализовано:** защищённая учётная запись, шифрование записей, синхронизация между устройствами, онлайн-доступ ChatGPT к данным, автоматический импорт Garmin. Эти функции требуют отдельного проектирования и настройки.
